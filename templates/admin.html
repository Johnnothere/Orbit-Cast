Add an event by link

Paste the event's own page. It gets fetched, read, and checked against the catalog rules - London or genuinely online, upcoming, a real event page, not an aggregator card, not already listed. If every check passes it goes straight in.

Events added by link

Add a recurring organiser

Paste any Luma organiser link — a calendar (lu.ma/cal-…), a vanity calendar URL (luma.com/londonai), or a person's host profile (luma.com/user/…). No cal- id needed: the link is resolved to one, which is also what stops the same organiser being tracked twice under two URLs.

It gets checked against their real upcoming events: already tracked, genuinely London or online, and a category OrbitCast hosts. From then on every refresh takes only their London and virtual events — anything in San Francisco, Singapore or anywhere else is dropped automatically, with nothing for you to review.

Tracked organisers

Approved from here and scraped every refresh. Pausing keeps the record but stops the scrape - a quiet organiser is not a dead one.

Discovered leads

Organisers the scraper found hosting events we already ingest, or on Luma's London feed. Proposals only - nothing here feeds until you check and add it.
